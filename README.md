# Karim Elsalahy — Cloud, DevOps & Security

Recruiter portfolio: [https://raidensec.github.io/](https://raidensec.github.io/)

## Site files

The published site is in `dist/`. Edit `dist/index.html`, `dist/styles.css`, and `dist/main.js` to update the portfolio.

## Deployment

Pushes to `main` run `.github/workflows/pages-deploy.yml`. The workflow uploads `dist/` as the GitHub Pages site and deploys it. You can also start it manually from the repository’s Actions tab.

This site is open source. [Improve this page](https://github.com/Raidensec/raidensec.github.io/edit/main/README.md).
